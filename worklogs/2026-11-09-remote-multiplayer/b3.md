# 第三批小步施工：一键本机联机自检

日期：2026-11-09。对应[需求](requirement-gap.md)。本批仅增加电脑自检入口，不扩展玩法、手机界面、协议或公网部署。

## 实现

- `server/start.cjs --smoke-test`先沿用原有核心编译/依赖检查，再运行`server/smoke.cjs`；也可使用server子包的npm run smoke。
- 使用独立临时服务、127.0.0.1随机端口和随机口令，忽略正常服务的环境配置，避免占用现有端口或进入现有房间。不输出自检口令。
- 实际命令使用ws客户端，依次验证HTTP健康、蓝队建房、红队加入、双方准备、初始同帧一致、一次合法发射及双方相同Simulating快照。复用真正LanClient，不另造协议。
- 每个连接/协议等待默认5秒；失败标注阶段并传回非零退出码。finally清理心跳、客户端及临时服务，只有全部成功和清理完成后才打印总通过。此自检只覆盖本机链路，不覆盖整局、手机或公网。
- `tests/server-smoke.test.cjs`增加4项针对流程与失败清理的测试。没有新增依赖或改动游戏运行代码。
