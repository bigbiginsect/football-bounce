# 球员库、技能与能力档

日期：2026-10-10。状态：代码、图片及 Creator 资源导入已完成；运行预览待验收。

## 目标与范围

- 延续现有 16 人球员库，为球员提供红 > 金 > 紫 > 蓝的能力档展示；梅西、C 罗归红档。
- 所有在册球员具备可描述且可实际生效的技能，沿用 Command / GameState 权威边界。
- 头像参照用户图片的正面球星插画、暖色内底和深色圆形徽章风格；补齐缺少的头像，尽量统一现有肖像表现。

## 当前状态与差距

- 16 人只有 6 张头像，其他人在仓库和阵容中显示姓名占位。
- 仅 C 罗 `aim-wobble` 和内马尔 `ball-hit-encore` 有真实技能；球员目录无能力档。
- UI 卡片没有按稀有度显示颜色，综合分对重量等五项简单平均，不适合直接作为能力档依据。

## 验收条件

- 球员目录校验能力档、技能 ID 与参数；红金紫蓝档案和卡面颜色一致。
- 每名球员有可用技能，技能在规则或物理适配层确实产生效果；外部命令不能自报效果。
- 新头像进入 `assets/resources/portraits/`，资源能由 Creator 导入并显示；目录中无人需要姓名占位。新资源 `.meta` 已由 Creator 生成。
- 类型检查、自动化测试、`git diff --check` 通过；Creator 预览验证仓库、阵容和比赛。

## 资料与设计决定

- 暂未找到可核实的《足球弹弹乐》或《碰撞全明星》官方技能清单，不把其他足球游戏的技能写成这两款的原版设定。
- 参考 [EA SPORTS FC Mobile 官方玩法说明](https://www.ea.com/ea-originals/news/gameplay-guide)中的强力射门、冲刺等概念，以及 [eFootball 官方玩法介绍](https://www.konami.com/efootball/en-us/page/overview)中的球员技能机制，设计适合本项目弹射碰撞规则的原创效果。
- 各档归属、具体技能参数均为本批可调整的设计假设，不代表现实球员客观排名。

## 不在本次范围

- 卡池、付费抽卡、球员成长、联机同步协议、Android 打包。
