## 关键决策

- “直接进球”按整个开球发射模拟判断，而不是尝试推断某次球员或皮球碰撞；开球回合内进入任一球门都统一违例，避免出现乌龙或碰撞路径绕过规则。
- 开球限制属于权威 `GameState`，不能只放在 UI 或一次性动画中；这样快照恢复及未来联机权威端能得到相同结算。
- 违例换边以本次发射操作者为基准，不以检测到的得分方为基准；任何直接入门都由另一方重新开球。
- 聚焦布局只在当前仓库页面会话中生效；重新进入仍从 1/3 默认布局开始。这样不新增持久 UI 状态，也不改变阵型数据。
- 力量属性不改变现有冲量公式，只增加力度盘视觉上限映射；50 分仍恢复原 `powerCircleMaxRadius`，避免基础手感漂移。
