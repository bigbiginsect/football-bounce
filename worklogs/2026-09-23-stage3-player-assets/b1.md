# 阶段 3 · 首批球员资产与阵容接口施工记录

日期：2026-09-23
对应目标：首批五位球星头像和属性入库，默认本地 5v5 显示圆形头像，并为未来选人站位界面提供阵容输入。

## 实现内容与关键文件

- `assets/resources/config/players.json` 与 `assets/resources/portraits/`：录入梅西、C 罗、姆巴佩、德布劳内、范戴克五人评分和 imagegen 生成的 PNG；Creator 3.8.8 导入并生成目录、图片、JSON 和新脚本的 `.meta`。
- `core/PlayerCatalog.ts`、`core/Lineup.ts`：目录/技能占位验证、50 分基准属性映射、默认两队名单及五人站位校验。队内模板唯一、跨队可重复。
- `core/GameState.ts`、`core/PrototypeConfig.ts`：状态结构升级为 v3，记录目录版本；标准比赛接受外部阵容，保持原对称默认坐标，配置版本更新为 `stage3-001`。
- `adapters/physics/CocosPhysics.ts`：每个实例按模板设置碰撞体质量和最大发射冲量；球员半径、阻尼、皮球及回合规则未调整。
- `presentation/Boot.ts`、`presentation/PrototypeView.ts`：显式加载资源包、目录和五张 SpriteFrame；十个实例各有缓存的椭圆遮罩头像节点，重开复用或按模板变化替换；精度决定瞄准线长度。
- `docs/player-assets.md`、`README.md`、`ROADMAP.md`、`AGENTS.md`、`env_requirement.md`：记录后续录入流程、阶段状态和本机已核实环境。

## 关键决策与生成记录

- 五人属性按计划采用主观游戏评分，重量/力度/精度依次为：梅西 55/84/96、C 罗 78/96/82、姆巴佩 62/90/82、德布劳内 70/84/94、范戴克 95/77/78。评分 50 对应旧质量、冲量、瞄准线，保证旧基准仍可比较。
- imagegen 内置工具逐人生成正方形头像。梅西先生成并确定线条、底色、构图；尝试将其图片仅作下一位的风格参考时，生成器以 `public-figure` 输入审核拒绝，因此其余四人按同一文字模板独立生成。最终提示词模板和各人的身份特征已写入 `docs/player-assets.md`，原图复制入工程，未覆盖既有资源。
- 圆形由运行时 `Mask.Type.GRAPHICS_ELLIPSE` 完成，队色外环仍由场上图形绘制。目录 JSON 和头像先异步加载完才创建比赛，缺失资源会显示启动错误。
- Creator 网页预览首次启动时因资源包尚未就绪，`resources.load('config/players')` 报无法解析请求。改为显式 `assetManager.loadBundle('resources')` 后，用户重新启动预览，画面正常；本会话网页预览亦显示十张头像。
