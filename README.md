# 足球弹弹乐

基于 Cocos Creator 3.8.8 / TypeScript 的手机 2D 桌球式足球游戏。

阶段 2 本地双人完整对局已完成（2026-09-23 用户确认收工，stage2-001）：标准模式 3 分钟、蓝红各 5 人、按种子随机先手、20 秒瞄准超时、完整过线进球、进球复位、比分/终局及重新开始均已接入。完整类型检查及 58 项自动化测试通过，用户在 Creator 实际运行后确认“可以玩”并接受阶段交付。阵型由未来玩家选择，本阶段不固定 2-2-1、1-2-2 等分配。

阶段 3 首批球员资产已接入：梅西、C 罗、姆巴佩、德布劳内、范戴克各有圆形卡通头像和重量、力度、精度，双方可复用同一球星。标准比赛仍有默认开局，同时提供供未来选人站位界面调用的阵容输入；本批完整类型检查及 70 项自动化测试通过，Creator 预览已看到十个头像。阶段 3 其余界面与体验内容继续推进。

阶段 0 已完成：工程重新打开、Creator 编辑器内运行预览与重复启动、完整类型检查和 18 项核心测试均通过。见 [复验记录](worklogs/2026-09-20-stage0-foundation/b2.md)。
