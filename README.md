# 足球弹弹乐

基于 Cocos Creator 3.8.8 / TypeScript 的手机 2D 桌球式足球游戏。

阶段 2 本地双人完整对局已完成（2026-09-23 用户确认收工，stage2-001）：标准模式 3 分钟、蓝红各 5 人、按种子随机先手、20 秒瞄准超时、完整过线进球、进球复位、比分/终局及重新开始均已接入。完整类型检查及 58 项自动化测试通过，用户在 Creator 实际运行后确认“可以玩”并接受阶段交付。阵型由未来玩家选择，本阶段不固定 2-2-1、1-2-2 等分配。

阶段 3 已接入六名球员、赛前阵容和层叠式球员仓库：阵容页右滑可跟手进入仓库，上方约 1/3 显示球场、当前首发和 `2-1-2`、`2-2-1`、`1-2-2` 三个可选阵型，点击阵型后球场聚焦到约 3/4，仓库仍可从下方上拉为全屏；选择槽位后可用“上场”替换球员，“信息”可查看重做后的头像、俏皮话、五项参数和预留技能区。蓝红两队独立保存阵型与阵容，确认后比赛使用对应开局坐标。比赛现已增加开球直接入门违例换边规则、无箭头三层立体瞄准线，以及精度控制线长、力量控制力度盘上限的视觉差异。HUD、进球/违例/超时/终局反馈和五类原型音效均已接入。完整类型检查和 95 项自动化测试通过；本批 Creator 交互试玩仍待完成，详见 [阵型聚焦、开球违例与瞄准反馈需求](worklogs/2026-09-28-kickoff-aim-formation-focus/requirement-gap.md)、[层叠仓库与阵型需求](worklogs/2026-09-28-layered-warehouse-formations/requirement-gap.md) 和 [球员仓库需求](worklogs/2026-09-24-player-warehouse/requirement-gap.md)。
