# 足球弹弹乐

基于 Cocos Creator 3.8.8 / TypeScript 的手机 2D 桌球式足球游戏。

阶段 2 本地双人完整对局已完成（2026-09-23 用户确认收工，stage2-001）：标准模式 3 分钟、蓝红各 5 人、按种子随机先手、20 秒瞄准超时、完整过线进球、进球复位、比分/终局及重新开始均已接入。完整类型检查及 58 项自动化测试通过，用户在 Creator 实际运行后确认“可以玩”并接受阶段交付。阵型由未来玩家选择，本阶段不固定 2-2-1、1-2-2 等分配。

阶段 3 当前为 `players-006` 的 20 名球员，全部配置头像、能力档和可生效技能。赛前采用统一纵向滚动的阵容与候补页面：三个阵型、五名首发及四列候补卡，候补不重复首发；长按 0.2 秒拖动换人或交换首发，边缘自动滚动，轻点查看详情。五类技能为瞄准干扰、命中追加行动、强力发射、瞄准增强、质量增强。重量动量碰撞、立体旋转皮球、四角弹簧、开球违例、三层瞄准线、比赛反馈和原型音效保留；比赛顶部比分、时钟及状态分行，信息栏与上方球门分离。详见 [统一选人记录](worklogs/2026-10-09-unified-lineup-scroll/b3.md)、[球员扩充记录](worklogs/2026-10-10-player-roster-skills-rarity/requirement-gap.md) 和 [顶部覆盖修复](worklogs/2026-09-24-stage3-match-feedback/b2.md)。
