# 足球弹弹乐

基于 Cocos Creator 3.8.8 / TypeScript 的手机 2D 桌球式足球游戏。

阶段 2 本地双人完整对局已完成（2026-09-23 用户确认收工，stage2-001）：标准模式 3 分钟、蓝红各 5 人、按种子随机先手、20 秒瞄准超时、完整过线进球、进球复位、比分/终局及重新开始均已接入。完整类型检查及 58 项自动化测试通过，用户在 Creator 实际运行后确认“可以玩”并接受阶段交付。阵型由未来玩家选择，本阶段不固定 2-2-1、1-2-2 等分配。

阶段 3 已接入 16 名球员、赛前阵容与候补仓库统一页面：原六人使用头像，新增十人暂以姓名徽章占位；上方球场、五名首发和 `2-1-2`、`2-2-1`、`1-2-2` 三个阵型与下方候补仓库连续纵向滚动；普通滑动浏览，长按球员后拖入位置换人或交换首发，靠近边缘自动滚动。轻点球员查看信息，不再左右切页、抽屉覆盖或按钮上场。重量现在明显改变碰撞质量且不抵消起步速度，力量与精度的相近评分差也已放大；比赛球员圆片半径小幅增至 `0.30 m`，皮球增加球面明暗、平动阴影和不对称旋转标记，四个场角加入满弹性卡通弹簧碰撞体。首批技能已启用：C 罗概率干扰对手下一次瞄准，内马尔每第 3 次本人正常行动在皮球碰到敌方后可追加一次行动。开球违例、三层瞄准线、HUD、事件反馈和五类原型音效继续保留。统一页面需求与本批验收见 [连续滚动选人需求](worklogs/2026-10-09-unified-lineup-scroll/requirement-gap.md)。其他能力详见 [比赛圆片尺寸与首批技能需求](worklogs/2026-09-29-player-skills-token-size/requirement-gap.md)、[球员、重量碰撞与角落弹簧需求](worklogs/2026-09-29-player-weight-ball-corner-springs/requirement-gap.md)、[阵型聚焦、开球违例与瞄准反馈需求](worklogs/2026-09-28-kickoff-aim-formation-focus/requirement-gap.md) 和 [层叠仓库与阵型需求](worklogs/2026-09-28-layered-warehouse-formations/requirement-gap.md)。

当前完整 TypeScript 类型检查及 112 项自动化测试通过。2026-10-09 用户自行试玩后反馈统一页面其他交互无问题；长按等待按其反馈从 0.3 秒缩短为 0.2 秒，最新阈值已通过自动化边界验证。球员尺寸、C 罗摆幅和内马尔追加行动的实际手感继续保留为试玩事项。
