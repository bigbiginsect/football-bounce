# 足球弹弹乐

基于 Cocos Creator 3.8.8 / TypeScript 的手机 2D 桌球式足球游戏。

当前建设工程与验证基础，启动场景为 `assets/scenes/Boot.scene`。发射物理、本地完整对局和局域网联机按路线图继续推进，最终交付为支持同局域网双 Android 手机对战的 APK。
